## <a name="introducción">🤖 Introducción</a>

Este proyecto es una galería web bilingüe (inglés y coreano) para presentar los principales productos que la empresa Brolem exporta. Cada producto se muestra en un catálogo visual, originalmente en PDF y renderizado como imágenes para facilitar la navegación. El usuario puede cambiar de idioma, ver los catálogos y descargar recursos.

---

## <a name="tecnologías">⚙️ Tecnologías</a>

- **React** (framework frontend)
- **Vite** (herramienta de construcción)
- **JavaScript** (lógica)
- **Tailwind CSS** (estilos)
- **PDF.js & react-pdf** (renderizado PDF, imágenes desde PDFs)
- **Soporte multilenguaje** (inglés y coreano)

---

## <a name="características">🔋 Características</a>

- 🌏 **Soporte bilingüe**: Interfaces en inglés y coreano.
- 🖼️ **Galería de imágenes desde PDF**: Los catálogos de productos se muestran como imágenes.
- 📑 **Catálogo de productos**: Listado organizado con navegación y detalles.
- 🎨 **Interfaz moderna**: Responsive, limpia y fácil de usar.
- ⚡ **Carga rápida**: Optimizado con Vite y assets comprimidos.
- 🔗 **Recursos descargables**: Acceso a PDFs o imágenes de cada producto.

## <a name="instalación-rápida">🤸 Instalación Rápida</a>

**Requisitos**

- [Git](https://git-scm.com/)
- [Node.js & npm](https://nodejs.org/)

**Instalación**

```bash
git clone https://github.com/BrolemDev/ProductsBrolem.git
cd ProductsBrolem
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

---

## <a name="uso">🕸️ Uso</a>

1. Inicia la aplicación localmente o visita el sitio desplegado.
2. Selecciona idioma (inglés o coreano).
3. Navega por la galería de productos.
4. Haz clic en un producto para ver su catálogo en imágenes.
5. Descarga recursos o contacta a Brolem para más información.

---

## <a name="personalización">🎨 Personalización</a>

- Agrega nuevos productos colocando sus assets PDF/imagen en el directorio correspondiente.
- Actualiza los datos de los productos en los archivos JS/catalogo.
- Modifica estilos y textos para adaptar a tu marca o idioma.
